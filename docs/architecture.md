# Architecture

- `backend/main.py`: FastAPI application entry point
- `backend/app/api`: API routes
- `backend/app/core`: configuration and logging
- `backend/app/models`: Pydantic schemas
- `backend/app/services`: application services
- `backend/quant_engine`: quantitative calculations
- `data_pipeline`: future market-data ingestion and validation
- `frontend`: future web dashboard
- `mobile`: future mobile application
